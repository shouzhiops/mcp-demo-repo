# 人物关系图谱进阶优化 (PersonGraph Advanced) Spec

## Why
在上一轮优化中，我们完成了图谱的多维实体接入、双击多跳扩展及风险高亮，但对比 PRD 5.2 节的要求，图谱仍存在 3 个关键高阶差距：图谱内检索缺失、最短路径探路未实现、以及右键菜单的业务流转未真实打通。我们需要补齐这三项能力，实现真正的图谱闭环分析。

## What Changes
- 新增图谱内检索输入框，快速高亮定位节点。
- 实现基于算法的最短路径探路功能（Ctrl/Cmd 选中双节点后高亮路径）。
- 真实打通右键菜单的业务流程（如唤出新增纠纷弹窗，或带参跳转至台账详情页）。

## Impact
- Affected specs: 关系图谱深度交互与业务闭环能力。
- Affected code: `src/pages/admin/PersonGraph.tsx`。

## ADDED Requirements
### Requirement: 图谱检索与探路
The system SHALL provide 图谱内检索和最短路径探路功能。

#### Scenario: 最短路径探路
- **WHEN** 用户按住 Ctrl/Cmd 键依次点击两个不相邻的节点，并触发“关系探路”
- **THEN** 系统计算出两节点间的最短路径，高亮该路径上的节点与连线，并将画布中其余非相关节点灰显。

#### Scenario: 业务菜单真实流转
- **WHEN** 用户在人员节点右键并点击“新增纠纷记录”
- **THEN** 界面真实弹出新增纠纷的表单，并在提交后同步更新后端数据与图谱展示。

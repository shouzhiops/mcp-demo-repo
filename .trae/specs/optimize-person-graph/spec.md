# 深度优化人物关系图谱 (PersonGraph) Spec

## Why
当前的人物关系图谱仅实现了初阶的静态展示，缺乏PRD 5.2 章节中要求的多维度数据实体（如单位、工单）以及深度交互能力（多跳扩展、图例过滤、风险高亮、右键菜单），需要对齐PRD进行深度优化，提升实战分析与治理决策价值。

## What Changes
- 扩展后端图谱 API 数据源，接入“单位 (Unit)”和“异常预警工单 (Order)”节点及对应连线。
- 新增图谱增量多跳接口支持（双击扩展二度关系）。
- 前端增加图例过滤器（Legend Filter）和布局切换功能。
- 定制化各个节点类型的 Tooltip 悬停展示字段，对齐PRD要求。
- 增加高危节点（如危房、待处理纠纷、高优工单）的红色呼吸预警特效。
- 增加节点右键菜单（Context Menu）以打通图谱分析与业务流转的闭环。

## Impact
- Affected specs: 关系图谱交互能力、数据源关联能力。
- Affected code: `api/src/index.ts`, `src/pages/admin/PersonGraph.tsx`。

## ADDED Requirements
### Requirement: 图谱多维实体与交互升级
The system SHALL provide 完整的“人、地、事、物、组织”节点映射及深度交互。

#### Scenario: 双击多跳扩展
- **WHEN** 用户双击画布上的某个非核心“人员”或“房屋”节点
- **THEN** 前端调用增量接口获取该节点的二度社会/业务关系，并将新节点和连线无缝叠加到当前画布上，实现图谱生长。

#### Scenario: 风险节点预警
- **WHEN** 图谱渲染包含高风险特征的节点（例如：状态="待处理"、优先级="高"、房屋状态="危房"）
- **THEN** 该节点呈现带有红色阴影发光或呼吸灯动效，以提示网格员重点关注。
